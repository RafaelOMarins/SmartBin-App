# ♻️ SmartBin Mobile Application

Mobile application developed with React Native with NativeWind for the SmartBin project.  
The app allows users to monitor the trash bin status remotely through real-time data sent by the ESP32 using the Adafruit IO platform.

---

## 📌 About the Project

SmartBin is an intelligent waste monitoring system designed to optimize waste management and provide a better user experience through IoT technologies.

This mobile application acts as the interface between the user and the SmartBin hardware, displaying updated information about the bin’s fill level directly on the smartphone.

---

## 🚀 Features

- 📊 Real-time waste level monitoring
- 📱 Mobile-first interface built with React Native
- 🔄 Communication with ESP32 via Adafruit IO API
- 📈 Graphical visualization of sensor data
- 🌐 Remote access to SmartBin status
